- ✅ **Character Frequency**: Count the frequency of each character in a string.

- ✅ **Optimized Prime Printing**: Improve performance of prime number generation.

  - At least one digit
  - At least one special character

### 🔄 Conversions
- ✅ **String to Integer (atoi)**: Convert a string to an integer.
